## 📖 Sobre o Repositório

Este repositório reúne todas as aplicações desenvolvidas durante o curso de **React Native da DIO (Digital Innovation One)** — uma jornada prática do zero ao desenvolvimento mobile profissional.

Cada projeto aqui representa um conceito aprendido na prática: desde os fundamentos de componentes e eventos até navegação entre telas, acesso à câmera e captura de mídia. O objetivo não é só concluir o curso, mas construir uma base sólida para aplicações mobile reais com React Native e Expo.

> *"Concentre-se no processo. Cada commit é um passo."*

## 🚀 Projetos Desenvolvidos

| # | Pasta | Descrição | Conceitos Aplicados |
|---|-------|-----------|---------------------|
| 01 | `bat-sinal` | App temático do Batman que simula o acionamento do Bat-Sinal com animação e efeito visual | `Animated API`, `StyleSheet`, gerenciamento de estado com `useState` |
| 02 | `pass-generetor` | Gerador de senhas seguras e customizáveis com opções de comprimento e tipos de caracteres | Lógica de algoritmo, `TextInput`, `Clipboard API`, componentes controlados |
| 03 | `cam-aula` | Integração com a câmera do dispositivo para captura de fotos em tempo real | `expo-camera`, permissões de dispositivo, preview de mídia |
| 04 | `video-capture` | App de captura e manipulação de vídeos, com preview e acesso à galeria | `expo-av`, `expo-media-library`, gerenciamento de mídia nativa |
| 05 | `components-overview` | Catálogo interativo dos principais componentes base do React Native | `View`, `Text`, `Image`, `ScrollView`, `FlatList`, `TouchableOpacity` |
| 06 | `events` | Estudo aprofundado sobre o sistema de eventos de toque e interação no mobile | `onPress`, `onLongPress`, `PanResponder`, feedback háptico |
| 07 | `react-nav` | Implementação de navegação entre múltiplas telas com React Navigation | `Stack Navigator`, `Tab Navigator`, passagem de parâmetros entre rotas |

## ▶️ Como Executar

### Pré-requisitos

Antes de começar, certifique-se de ter instalado:
- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [Git](https://git-scm.com/)
- [Expo Go](https://expo.dev/client) no seu dispositivo móvel (iOS ou Android)

### Passo a passo

**1. Clone o repositório**

```bash
git clone https://github.com/Rafa-Pontes/DIO-REACT-NATIVE.git
```

**2. Acesse a pasta do projeto que deseja executar**

```bash
cd DIO-REACT-NATIVE/bat-sinal
```

> Substitua `bat-sinal` pelo nome de qualquer projeto da tabela acima.

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o servidor Expo**

```bash
npx expo start
```

**5. Abra no seu dispositivo**

Escaneie o QR Code exibido no terminal com o aplicativo **Expo Go** no seu celular.
Para rodar no emulador, pressione `a` (Android) ou `i` (iOS) no terminal.
